How to Go Live & Keep Pushing Changes
  • 1

    Push this Launcher to GitHub

    Save and commit this file to your git repository: git add . then git commit -m "add web launcher" and git push origin main.

  • 2

    Click the "Make It Live" Button Above

    It will take you to Vercel. Log in using your GitHub account and click **Import** next to the Pretty-Thread-website repository.

  • 3

    Deploy & Enjoy

    Vercel will build the Next.js site automatically and generate your live website URL (e.g. pretty-thread-website.vercel.app) in 1-2 minutes!
